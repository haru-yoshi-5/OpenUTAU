# AI Tuning Studio（仮称）

就職活動のプレゼンテーション用に作っているポートフォリオ作品です。

OpenUtau で作成したプロジェクトファイル（USTX）をブラウザで読み込み、ノート・歌詞・ピッチカーブを可視化する Web アプリです。最終的には、調声プリセットや AI による表現提案を使って、変更前後を比べながら調声を進められるようにします。

> OpenUtau の公式サービスではありません。OpenUtau プロジェクトとは提携していない、独立した非公式ツールです。

## 現在の範囲（Phase 1：基盤と互換性の検証）

- USTX の読み込みと検証
  - 拡張子、サイズ（20MB まで）、UTF-8、YAML の構文と構造を検証します。
  - エイリアスと独自タグは拒否します。
- ピアノロールの表示
  - ノート、歌詞、テンポ、小節を表示します。
  - ピッチカーブは、OpenUtau の計算を近似して表示します（下記「ピッチ計算」を参照）。
- 無変更での書き出し
  - 読み込んだときのバイト列をそのまま出力します。
- 互換性チェック
  - 再シリアライズ（データを YAML に書き直すこと）の後に読み込み直し、元データと一致するかを検証します。
  - 一致しない場合は出力を止めます。

読み込んだファイルはブラウザ内でのみ処理し、サーバーへは送信しません。

### ピッチ計算

OpenUtau の `RenderPhrase` と同じ順序で重ねます。

1. 音高の段差
2. ビブラート
3. ピッチ点
4. PITD カーブ

音素単位の補正とスプライン補間は省いた近似です。

## 技術構成

- Next.js（App Router）
- TypeScript
- Tailwind CSS
- shadcn/ui
- `yaml`（YAML の解析と文書の保持）
- Zod（データ構造の検証）
- Vitest（テスト）
- Biome（lint とフォーマット）

## 開発

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # ユニットテスト
npm run lint       # Biome
npm run typecheck  # 型チェック（事前に `npx next typegen` が必要）
npm run build
```

`public/samples/demo.ustx` は、メロディと歌詞を自作したデモ用サンプルです。歌声ライブラリは指定していません。
