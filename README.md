# OpenUtau AI Tuning Studio（仮称）

OpenUtau の調声作業を支援する、個人開発の Web アプリです。

OpenUtau で作成したプロジェクトファイル（USTX）をブラウザで読み込み、ノート・歌詞・ピッチカーブを表示します。今後は調声プリセットとローカル AI による提案を加え、変更前後を比べながら調声を進められるようにします。編集結果は USTX 形式で OpenUtau に戻せるようにします。

> OpenUtau の公式サービスではありません。OpenUtau プロジェクトとは提携していない、独立した非公式ツールです。

## 開発方針

1. 従量課金が発生しない構成にする（有料 AI API・クラウド DB を必須にしない）
2. OpenUtau とのファイル互換性を保つ
3. AI がなくても調声編集ができるようにする
4. 編集操作を直感的にする

USTX ファイルはブラウザ内だけで処理し、外部のサーバーへは送信しません。

## 現在の範囲（Phase 1：USTX ビューア）

- **USTX の読み込みと検証**
  - 拡張子、サイズ（20MB まで）、UTF-8、YAML の構文と構造を検証します。
  - エイリアスと独自タグは拒否します。OpenUtau はどちらも出力しないため、正規のファイルには影響しません。
- **プロジェクト情報の表示**：テンポ、拍子、トラック、パート、ノート数を表示します。
- **未対応データの通知**
  - 新しすぎる形式・古い形式の USTX には警告を出します。
  - 音声パートや PITD 以外の表現カーブなど、表示に反映していないデータがあることを知らせます。
- **ピアノロール（Konva）**
  - ノート、歌詞、小節、テンポ、ピッチカーブを Canvas に描画します。
  - ドラッグ・ホイール・キーボードで移動し、拡大・縮小できます。
  - 画面に見えている範囲だけを描画します。
- **無変更での書き出し**：読み込んだときのバイト列をそのまま出力します。
- **互換性チェック**
  - 再シリアライズした結果を読み込み直し、元データと一致するかを検証します。
  - 一致しない場合は出力を止めます。

### ピッチ計算

OpenUtau の `RenderPhrase` と同じ順序で重ねます。

1. 音高の段差
2. ビブラート
3. ピッチ点
4. PITD カーブ

音素単位の補正とスプライン補間は省いた近似です。

## 技術構成

| 領域           | 採用技術                                                         |
| -------------- | ---------------------------------------------------------------- |
| ツールチェーン | [Vite+](https://viteplus.dev/)（Vite / Vitest / Oxlint / Oxfmt） |
| UI             | React 19 + TypeScript                                            |
| CSS            | Tailwind CSS 4                                                   |
| 描画           | Konva + react-konva                                              |
| 状態管理       | Zustand                                                          |
| USTX 解析      | `yaml`（Document API で元の構造を保持）+ Zod                     |

### ディレクトリ構成

```text
src/
├── lib/ustx/            USTX の読み込み・書き出し・ピッチ計算（フレームワーク非依存）
├── stores/              Zustand ストア（プロジェクト・表示状態）
├── features/
│   ├── piano-roll/      Konva のピアノロールと座標計算
│   └── viewer/          ビューア画面
└── components/ui/       ボタン・カード・警告表示などの共通部品
```

## 開発

Node.js `^22.18.0 || ^24.11.0 || >=26.0.0` が必要です。

```bash
npm install
npm run dev      # vp dev：開発サーバー（http://localhost:5173）
npm run check    # vp check：フォーマット・lint・型チェック
npm test         # vp test：ユニットテスト
npm run build    # vp build：本番ビルド（dist/）
```

`public/samples/demo.ustx` は、メロディと歌詞を自作したデモ用サンプルです。歌声ライブラリは指定していません。
